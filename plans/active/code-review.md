# 代码审查计划 (Code Review)

> 创建: 2026-01-21
> 状态: 进行中

## 目标

全面审查 akshare-go 项目，确保与 Python 源代码严格一致：
1. 文件完整性：所有 Python 文件都有对应的 Go 实现
2. 函数完整性：所有 Python 函数都已在 Go 中实现
3. 函数签名一致：参数和返回值与 Python 版本匹配
4. 测试覆盖：每个函数都有对应的单元测试

## 审查方法

### 阶段 1: 模块清单生成
- [ ] 获取所有 Python 模块列表
- [ ] 获取所有 Go 模块列表
- [ ] 生成对比矩阵

### 阶段 2: 逐模块深度审查 (按 A-Z 顺序)
对每个模块执行：
1. 列出 Python 文件中的所有函数
2. 列出 Go 文件中的所有函数
3. 对比函数清单，标记缺失项
4. 检查函数签名（参数名、类型、默认值）
5. 检查函数返回值结构
6. 验证测试文件存在性
7. 验证每个函数都有测试用例

### 阶段 3: 问题修复
- [ ] 实现所有缺失的函数
- [ ] 修正函数签名不匹配
- [ ] 补充缺失的测试用例
- [ ] 修复测试失败

### 阶段 4: 验证
- [ ] 编译所有代码
- [ ] 运行完整测试套件
- [ ] 生成覆盖率报告
- [ ] 更新 STATUS.md
